Comment ma classe sait si une image est une couleur : Dans ce programme, le classeur examine le mot qui suit le dernier souligné du nom. Si ce mot est exactement normal, rugosite, hauteur, metal ou occlusion, il choisit LINEAIRE, car l'image contient des données. Dans les autres cas, il choisit SRGB, pour une image supposée représenter une couleur. Par exemple, brique_normal est linéaire et brique est sRGB.

Une image que ma regle classe mal : visage_normalise est classée SRGB, car son dernier mot est normalise et non normal. Si le fichier contient en réalité une carte de normales, son contenu devrait rester linéaire. Le décodage sRGB modifierait les valeurs des composantes, déformerait les vecteurs de normales et pourrait fausser l'éclairage.

Ce que je ferais a la place : Je ne peux pas vérifier une classe de textures existante dans le code actuel de DaneRHI : les sources consultées ne contiennent pas encore de classe de texture. Dans le vrai classeur, je transmettrais explicitement le rôle au moment du chargement, par exemple TextureEspace::SRGB pour une image de couleur et TextureEspace::Lineaire pour une carte de normales ou de rugosité. Cette métadonnée serait la source de vérité, indépendamment du nom du fichier.
